# NexaFlow / ECSU 2.0

**NexaFlow / ECSU 2.0** is a web application with a React, TypeScript, and Vite frontend, Python backend functions, and PostgreSQL migration files. The app includes dashboards and modules for incident monitoring, reports, legal information, security, and finance.

## Run the frontend

From `open-source-program-creation-main/`:

```bash
npm install
npm run dev
```

Build and lint:

```bash
npm run build
npm run lint
```

Backend and database need separate configuration; consult `open-source-program-creation-main/MIGRATION_EDITOR.md`.
