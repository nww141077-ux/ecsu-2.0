## 2. Технологии и структура

- Frontend: React 18, TypeScript, Vite, Tailwind CSS.
- Backend: независимые Python-функции.
- Данные: PostgreSQL; миграции в `db_migrations/`.
- Основной код интерфейса: `src/`, страницы — `src/pages/`, компоненты — `src/components/`.
- Backend-функции: `backend/`.

Состав репозитория может отличаться от описаний в старых экспортных материалах. Ориентируйтесь на реальные файлы и маршруты в текущей версии.

## 3. Запуск frontend локально

Требуется установленный Node.js и npm. В PowerShell или терминале перейдите в каталог проекта (`open-source-program-creation-main`) и выполните:

```powershell
npm install
npm run dev
```

Для production-сборки и линтера:

```powershell
npm run build
npm run lint
```

Frontend может отображать демонстрационные данные или обращаться к внешним endpoint'ам. Успешная сборка сама по себе не подтверждает доступность backend или корректность данных.

## 4. Backend и база данных

Python-функции расположены в `backend/` по модулям. Конкретный способ запуска и публикации зависит от платформы функций. В коде встречается переменная окружения `DATABASE_URL`; некоторые интеграции могут требовать дополнительные ключи и секреты.

Не помещайте реальные секреты, пароли, банковские реквизиты или `.env` в публичный Git-репозиторий. Перед запуском с настоящими пользователями отдельно проверьте аутентификацию, авторизацию, CORS, обработку персональных и финансовых данных, а также настройки production-БД.

Миграции находятся в `db_migrations/`. Перед применением к рабочей базе сделайте резервную копию и проверьте SQL и схему целевой БД.

## 5. Экспорт и перенос

1. Сохраните исходный проект и доступную историю в poehali.dev, если она доступна владельцу.
2. Сохраните архив экспортированного кода, текущую Git-историю и копию базы/ресурсов в защищённом месте.
3. Установите frontend-зависимости и выполните сборку; результат Vite по умолчанию — `dist/`.
4. Настройте хостинг SPA так, чтобы клиентские маршруты перенаправлялись на `index.html`.
5. Переносите backend, базу, файлы и секреты отдельно; не переносите секреты в браузерный код.
6. После переноса проверьте все маршруты и интеграции в новой среде.

Команды и параметры развёртывания уточняйте по актуальным настройкам выбранного хостинга. Сведения платформы и её условия могут меняться.
