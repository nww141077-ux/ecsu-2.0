# ECSU 2.0 для Windows

Это Electron-оболочка для опубликованной веб-системы ECSU 2.0. Она открывает сайт в отдельном настольном окне и создаёт ярлыки через установщик NSIS.

## Важно

- Для работы необходим интернет: интерфейс загружается с `https://ecsu-system-2026.web.app/egsu/start`.
- Это не устанавливает backend, базу данных или датчики на компьютер. Они должны быть отдельно опубликованы и настроены.
- Пока домен `escu-nww.com` не подключён к Firebase Hosting, используется адрес Firebase. После подключения его можно переопределить переменной среды `ECSU_DESKTOP_URL` (только HTTPS и разрешённые домены в `desktop/main.cjs`).
- Electron-окно не заменяет авторизацию сервера. Не размещайте в приложении секреты и не считайте владельческие страницы защищёнными, пока серверная проверка доступа не внедрена.

## Сборка установщика в Windows

Нужны Node.js LTS, npm и подключение к интернету. Откройте PowerShell в папке `open-source-program-creation-main` и выполните:

```powershell
npm install
npm run desktop:build:win
```

Установщик появится в `release\ECSU-2.0-Setup-1.0.0.exe`. Запустите его, выберите установку для текущего пользователя и оставьте включённым создание ярлыка на рабочем столе.

Передавать пароль, API-ключи или другие секреты при сборке не нужно.
