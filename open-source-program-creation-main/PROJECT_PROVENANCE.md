# Происхождение проекта и сохранение подтверждений

Этот чек-лист помогает сохранять материалы, относящиеся к истории проекта NexaFlow / ECSU 2.0. Он не подтверждает авторство сам по себе и не заменяет юридическую консультацию.

По сообщению владельца, проект создавался на сайте-конструкторе **poehali.dev**, после чего исходники экспортировались и размещались в GitHub. Сохраняйте доступные оригиналы, а не только пересказы или скриншоты.

## Что сохранить

- Исходный проект в poehali.dev: доступные версии, историю изменений, даты и идентификатор проекта.
- Каждый экспорт исходников: исходный ZIP без редактирования, дату получения и сведения, откуда он экспортирован.
- Git: репозиторий целиком, ветки, теги и историю коммитов; храните резервную копию отдельно от GitHub.
- Авторские материалы: макеты, тексты, изображения и заметки, созданные владельцем, с исходными файлами и датами.
- Зависимости и сторонние материалы: версии, лицензии, авторов/источники, обязательные notices и ограничения — см. `THIRD_PARTY_LICENSES.md`.
- Условия poehali.dev, действовавшие во время создания и экспорта, и переписку/подтверждения от платформы, если они доступны.

## Пример архивирования в Windows PowerShell

Запустите из корня локальной копии репозитория. Архивируйте исходники без `node_modules` и `dist`, если задача — зафиксировать историю исходного кода; при необходимости сохраните production-сборку отдельным архивом.

```powershell
$stamp = Get-Date -Format "yyyyMMdd-HHmmss"
$archive = "..\NexaFlow-source-$stamp.zip"
Get-ChildItem -Force | Where-Object { $_.Name -notin @("node_modules", "dist", ".git") } |
  Compress-Archive -DestinationPath $archive
Get-FileHash $archive -Algorithm SHA256 | Format-List
Get-Item $archive | Select-Object FullName, Length, CreationTimeUtc, LastWriteTimeUtc
```

Сохраните вывод с SHA-256 и датой в отдельной записи; не редактируйте исходный архив. Архивируйте `.git` отдельно, потому что пример исключает эту папку.

## Зафиксировать Git-историю

```powershell
git status --short --branch
git log --all --date=iso-strict --format="%H %ad %an %s" > ..\NexaFlow-git-history.txt
git bundle create ..\NexaFlow-git-history.bundle --all
Get-FileHash ..\NexaFlow-git-history.txt, ..\NexaFlow-git-history.bundle -Algorithm SHA256
```

Git-имена, даты и коммиты сами по себе не устанавливают личность автора или правовой статус. Сохраняйте исходный контекст и резервные копии.

## Хранение

Держите как минимум две резервные копии в разных местах, ограничьте доступ к личным данным и секретам, и периодически проверяйте контрольные суммы. Не публикуйте `.env`, ключи API, пароли, банковские данные или персональные данные в репозитории.
